# RPG Battle Game

A turn-based RPG battle game developed in Java as part of the Object-Oriented Programming course.

## Project Overview

The game allows players to fight through three tiers of increasingly challenging enemies, using different attack strategies, weapons, potions, and special abilities.

The game supports both manual gameplay through a Java Swing graphical interface and automatic gameplay with adjustable speed.

## Features

- Three tiers of enemies, including a final Dragon boss.
- Multiple enemy types with different attributes and abilities.
- Interchangeable attack strategies.
- Weapons with ammunition and reloading mechanics.
- Potions and special abilities.
- Player progression and rewards.
- Manual and automatic gameplay modes.
- Event-driven combat system.
- Swing graphical user interface.

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- Java Collections and Generics
- Event-driven programming

## OOP Concepts

The project demonstrates:

- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Composition
- SOLID design principles

## Project Structure

The source code is organized into packages according to their responsibilities, including characters, controllers, events, factories, and GUI components.

## How to Run

1. Clone the repository.
2. Open the project in your Java IDE.
3. Ensure the required Java version is installed.
4. Run the main application class.
